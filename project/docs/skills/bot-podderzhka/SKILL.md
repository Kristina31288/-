# Бот «Что сказать, когда…»

Отдельный бот только для этого проекта (не связан с HR, Битрикс24, 1С). Код: репозиторий `kristina31288/-`, папка `project/bot/`, подробности — `project/bot/README.md`.

## Где что
- `texts.py` — все тексты (тон «без нытья»: сначала дело, максимум одна фраза поддержки).
- `catalog.py` — продукты и цены; `knowledge.md` — база знаний ИИ; `faq.json` — ответы без ИИ.
- `safety.py` — кризисный детектор и передача человеку. ЛОГИКУ НЕ ОСЛАБЛЯТЬ. Кризисный ответ обязательно содержит 8-800-2000-122, 112, «не оставайтесь одни», обращение к специалисту.
- `llm.py` — GigaChat (адрес API сверить с документацией Сбера), системный промпт консультанта и продавца.
- `payments.py` — выдача покупок; вебхуки Продамус/ЮKassa ещё не реализованы.

## Правила изменений
1. Любое изменение — с тестами: `cd project/bot && python3 -m pytest -q` (все должны проходить).
2. Добавление разбора: `catalog.py` + `knowledge.md` + `faq.json` + PDF в `files/` + цена в бренд-буке.
3. Секреты только в `.env` (не коммитить). Данные хранить на сервере в РФ (152-ФЗ).
4. ИИ сразу говорит, что он ИИ; не обещает результат; не выдумывает скидки и отзывы; цена и возврат — до ссылки на оплату.
