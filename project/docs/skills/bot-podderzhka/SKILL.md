# Бот «Что сказать, когда…»

Отдельный бот только для этого проекта (не связан с HR, Битрикс24, 1С). Код: репозиторий `kristina31288/-`, папка `project/bot/`, подробности — `project/bot/README.md`.

## Где что
- `texts.py` — все тексты (тон «без нытья»: сначала дело, максимум одна фраза поддержки).
- `catalog.py` — продукты и цены; `knowledge.md` — база знаний ИИ; `faq.json` — ответы без ИИ.
- `safety.py` — кризисный детектор и уведомление владелице (сама владелица клиенту не пишет). ЛОГИКУ НЕ ОСЛАБЛЯТЬ. Кризисный ответ обязательно содержит 8-800-2000-122, 112, «не оставайтесь одни», обращение к специалисту.
- `llm.py` — GigaChat (адрес API сверить с документацией Сбера), системный промпт ИИ-помощницы «Виктория» (режимы: помощь, подбор разбора, замена разбора).
- `payments.py` — выдача покупок; вебхуки Продамус/ЮKassa ещё не реализованы.

## Правила изменений
1. Любое изменение — с тестами: `cd project/bot && python3 -m pytest -q` (все должны проходить).
2. Добавление разбора: `catalog.py` + `knowledge.md` + `faq.json` + PDF в `files/` + цена в бренд-буке.
3. Секреты только в `.env` (не коммитить). Данные хранить на сервере в РФ (152-ФЗ).
4. Виктория сразу говорит, что она ИИ-помощница, а не человек и не автор; не обещает результат; не выдумывает скидки и отзывы; цена и условие замены («если разбор не подойдёт — подберём другой») — до ссылки на оплату.
5. Консультаций нет: никаких кнопок, текстов и записи на консультацию. Кнопок и фраз «Написать автору», «Связаться с человеком», «живой человек» нет — на всё отвечает Виктория.
6. Возврат денег бот сам не предлагает и не рекламирует. Замена — одна на покупку: Виктория присылает другой разбор. Если человек настаивает на возврате или жалобе — Виктория принимает заявку, фиксирует её для владелицы, называет срок рассмотрения по оферте и e-mail для официальных претензий (только из оферты).
7. Внутреннее правило (клиенту не сообщать): после возврата денег этому пользователю продажи отключаются — не показывать ссылки на оплату и предложения разборов.
