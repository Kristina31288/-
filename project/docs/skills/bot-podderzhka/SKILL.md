# Бот «Что сказать, когда…»

Отдельный бот только для этого проекта (не связан с HR, Битрикс24, 1С). Код: репозиторий `kristina31288/-`, папка `project/bot/`, подробности — `project/bot/README.md`.

## Где что
- `texts.py` — все тексты (тон «без нытья»: сначала дело, максимум одна фраза поддержки). Представление: `VICTORIA_INTRO` и `VICTORIA_NAME_STORY`.
- `catalog.py` — продукты и цены; `knowledge.md` — база знаний Виктории; `faq.json` — ответы без ИИ (`answer_no_sell` — вариант без продаж).
- `safety.py` — кризисный детектор и распознавание намерений (возврат, файл, «не подошло», жалоба, мат, «позовите человека»). Кризисную ЛОГИКУ И ТЕКСТ `CRISIS_REPLY` НЕ МЕНЯТЬ и не ослаблять: 8-800-2000-122, 112, «не оставайтесь одни», обращение к специалисту.
- `support.py` — сценарии Виктории фиксированными текстами (до ИИ): возврат (причина кнопками `rf:r:*`, «Открылось» `rf:f:*`, `resolve_refund`), файл не пришёл, замена/подарок, жалоба, мат.
- `llm.py` — GigaChat (адрес API сверить с документацией Сбера), системный промпт Виктории: методика продаж, возражения, запреты, метки `[НЕТ_В_БАЗЕ]` и `[ВОЗВРАТ]`.
- `summary.py` + `scheduler.py` — ежедневная сводка владелице (каждый день 10:00 МСК), сроки по заявлениям о возврате.
- `followup.py` — цепочка советов, «Как прошла неделя?», замена, подарок для набора.
- `payments.py` — выдача покупок; вебхуки Продамус/ЮKassa ещё не реализованы.
- `VICTORIA.md` — роль, правила и примеры диалогов (целевое поведение), в т. ч. три ветки возврата.

## Правила изменений
1. Любое изменение — с тестами: `cd project/bot && python3 -m pytest -q` (все должны проходить; для тестов обработчиков нужен aiogram из `requirements.txt`).
2. Добавление разбора: `catalog.py` + `knowledge.md` + `faq.json` + PDF в `files/` + цена в бренд-буке.
3. Секреты только в `.env` (не коммитить). Данные хранить на сервере в РФ (152-ФЗ).
4. Виктория — ИИ-помощница: в первом сообщении представляется («Я Виктория — ИИ-помощница проекта «Что сказать, когда…».» + строка про имя), никогда не выдаёт себя за человека, автора или дочь автора. Не обещает результат, не выдумывает скидки, отзывы, дефицит, таймеры; цена — до упоминания оплаты; отвечает только из `knowledge.md`, иначе «Этого в моей базе нет» → вопрос в сводку. Автора не называть «психологом» без уточнения «по образованию».
5. Консультаций нет: никаких кнопок, текстов, ссылок (`CONSULT_LINK` удалён). Кнопок и фраз «Написать автору», «Связаться с человеком», «живой человек», команды `/reply` нет — на всё отвечает Виктория. Владелица с клиентами не переписывается.
6. Владелице — только **ежедневная сводка** (каждый день 10:00 МСК, одно сообщение на `OWNER_ID`): новые пользователи, покупки, замены, заявления о возврате (№, дата подачи, «осталось N дн.» до 10-дневного срока, ≤3 дня — «СРОЧНО», основание, user_id, e-mail оплаты, покупка), кому выдать файл, вопросы без ответа (без user_id и контактов). Кризисные уведомления — только при `NOTIFY_OWNER_ON_CRISIS=1` (по умолчанию 0). Технические уведомления «нет файла в files/» остаются.
7. Предмет продажи — PDF-файл, выдаётся сразу после оплаты (слово «доступ» как предмет продажи не использовать). Возврат — только в законных случаях: двойной/ошибочный платёж; файл не пришёл или не открывается и повторная выдача не помогла; срок рассмотрения — до 10 дней. Возврат бот сам не предлагает, не обещает, не спорит, законы не цитирует. На «верните деньги» — причина кнопками: «Платёж прошёл дважды» → e-mail оплаты + дата → заявление `double`; «Файл не пришёл или не открывается» → PDF заново + как открыть, «Открылось» / «Всё равно не открывается» → e-mail → заявление `file` (нет записи о покупке — сначала выдача файла через `/give`); «Другая причина» → один раз замена в течение 14 дней (для набора — подарок «Карта спокойного вечера», `files/04-podarok.pdf`, ключ `gift_evening`) → настаивает → e-mail → «Принимаю ваше заявление, его рассмотрят в течение 10 дней.» → заявление `other`. Решение владелицы: `/refunded <№>` (возврат выполнен в кабинете платёжного сервиса) или `/reject <№>` (отказ, клиенту ничего не пишется; `/reject <№> notify` — фиксированный текст `REJECT_NOTIFY`). Покупки на Wildberries — по правилам площадки, бот их не возвращает.
8. Отметка **no_sell навсегда** ставится ТОЛЬКО после `/refunded <№>` (не при подаче заявления и не при `/reject`): никаких продающих сообщений, цепочек, карточек с ценой, кнопок оплаты, апсейлов; «Разборы» — только описания; Виктория не предлагает покупки. Кризисный ответ и FAQ работают. Отметка сохраняется и после `/delete_me`.
9. Жалобы — спокойно, по делу, с решением (файл заново, замена). Мат — один нейтральный ответ «Готова помочь, если опишете, что не так.», без эскалации.
