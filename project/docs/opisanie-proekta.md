## 1. Как шёл проект (хронология)
1. **Старт.** Задача: недорогие обучающие продукты 999–2000 ₽, автор с педагогическим образованием. Команда из 4 аналитиков: рынок, аудитория, конкуренты и цены, воронка продаж.
2. **Первая версия — музыка.** Профиль автора (музыкальный колледж, преподаватель, артист оркестра, руководитель творческого коллектива) → ниша «музыка для родителей учеников ДМШ». Подсказки Яндекса показали слабый спрос («ребёнок не хочет заниматься музыкой» — 1–2 подсказки). Отказались.
3. **Расширение — педагогика и психология.** Диплом по психологии управления → анализ «любых обучений»: 5 500 поисковых подсказок Яндекса и Google по формулировкам болей, живые обсуждения родителей и педагогов, траты взрослых на обучение.
4. **Выбор продукта.** Библиотека PDF-разборов «Что сказать, когда…» по 299 ₽ — готовые фразы и план на неделю. Топ-3 боли: телефон и игры, грубость/закрытость подростка, уроки с криком.
5. **Производство.** Бренд-бук → 3 автора-эксперта → рецензент безопасности → рецензент-«мама» → главный редактор → вёрстка PDF, лендинг, бот, юридические шаблоны, маркетинг.
6. **Дизайн.** Референс владелицы (эдиториал-барокко). Варианты: тёмный с ангелами Рафаэля (отклонён: «будто мёртвый»), утверждён **«серый светлый»** с фото автора.
7. **Бизнес-правила.** Без консультаций; владелица не общается с клиентами; ИИ-помощница **Виктория**; возврат только по закону; ежедневная сводка.

## 2. Исследования — главные выводы
**Рынок (ноябрь 2026):** EdTech растёт медленно (+12% топ-100 за 2025), чек смещается к дешёвым продуктам, повторные продажи 55–58%. «Психология и отношения» ~19 млрд ₽, «Саморазвитие» +45%, программы для родителей — 2-е место по числу учеников на GetCourse (2025/26), траты на детей +25%. Импульсная покупка — 300–1 500 ₽, острая проблема «сегодня», узкий результат.

**Поисковые подсказки (5 500 фраз):** чаще всего родители ищут: «ребёнок не хочет учиться/делать уроки», «как не кричать на ребёнка из-за уроков», «как отучить от телефона/игр», «как общаться с подростком 14 лет», «ребёнок бьёт родителей», «берёт деньги без спроса», «как научить отвечать обидчику». Взрослые: «как перестать нервничать и накручивать себя», «как перестать злиться на близких».

**Живые обсуждения (форумы, mel.fm, Т—Ж):** родителям не хватает **готовых фраз** и ответа **«норма или пора к специалисту»**. Психолог — ~5 000 ₽/сессия, жалобы «нет прогресса» → ниша «дешевле и практичнее терапии». Педагоги: зарплаты, отчётность, родительские чаты, уход в репетиторство.

**Английский:** перенасыщен; без языковой квалификации автора не брать.

Файлы исследований: папка «Исследования» на Диске (стратегия, топ-10 ниш, сигналы поиска).

## 5. Путь клиента
Дзен/VK/Telegram/WB → бесплатная статья под поисковый вопрос → бот → согласие → «10 фраз» → прогрев (день 1: первая фраза; день 2: пример; день 3: «какая ситуация?» + карточка) → оплата 299/690 ₽ → PDF в Telegram и на e-mail → через 3 дня «Как прошла неделя?» → следующий разбор/набор или замена. Ориентир: из 1 000 читателей ~30–50 в боте, 2–3 покупки.

## 6. Бот и ИИ-помощница Виктория
- **Платформа:** Telegram, Python 3.11+, aiogram 3, SQLite; отдельный бот, не связан с HR/Битрикс24/1С. ИИ — GigaChat (легально из РФ); без ключа работает из базы ответов.
- **Виктория:** «Я Виктория — ИИ-помощница проекта… Меня назвали в честь Виктории — дочки автора». Подбор разбора (1–2 вопроса), работа с возражениями, без давления, без выдуманных скидок/отзывов, без обещаний результата.
- **Владелица не общается с клиентами.** Нет «Написать автору» и консультаций.
- **Возврат:** причина кнопками — двойной платёж / файл не открывается (повторная выдача) / другое (замена, для набора — подарок; если настаивает — заявление, рассмотрение до 10 дней). Пока заявление открыто — пауза продаж. `/refunded №` — возврат сделан, клиенту больше не продаём; `/reject №` — отказ, продажи возобновляются.
- **Ежедневная сводка** владелице в 10:00 МСК: подписчики, покупки, замены, заявления с отсчётом «осталось N дн.» («СРОЧНО» при ≤3), вопросы без ответа.
- **Безопасность:** кризисные слова → фиксированный ответ с 8-800-2000-122 и 112, без продаж; детектор ловит опечатки и латиницу.
- **Цепочка прогрева:** 3 сообщения, тихие часы 22:00–9:00, отписка /stop_tips.
- **Документы:** `bot/README.md` (запуск, VPS, бэкап, 152-ФЗ), `bot/VICTORIA.md` (12 диалогов).
- **Не сделано:** автоматическая выдача после оплаты (вебхук ЮKassa/Продамус), проверка с живым GigaChat и токеном Telegram.

## 7. Сайт (лендинг)
Один экран за другим: шапка «ЧТО СКАЗАТЬ, когда…» → первый экран: «Без крика. Без вины. С готовыми словами» + фото Кристины в арке + рукописные «телефон / грубость / уроки» → «Разборы» (графитовая полоса, арочные карточки с картинами и подписями-табличками, набор 690 ₽) → «Замкнутый круг» (каменная плашка, Тревога/Крик/Вина/Тишина, «Ребёнок не слушает? Дело не в нём и не в вас, а в словах») → «Шесть шагов» (купол) → «Автор» (Кристина, цитата о Виктории) → Вопросы → «Если ситуация острая» → подвал с реквизитами. Форм на сайте нет: все кнопки ведут в бот (данные — только в боте, проще с 152-ФЗ). Адаптив под телефон проверен.

## 9. Журнал решений владелицы
- Цена 299 ₽ / набор 690 ₽; формат PDF, без видео.
- Цвета: «серый светлый» (тёмный отклонён).
- Заголовки: «Без крика. Без вины. С готовыми словами»; «Ребёнок не слушает? Дело не в нём и не в вас, а в словах». «Ваш ангел» — отклонён.

- Автор: «психолог по образованию (психология управления)», не «психолог».
- Возврат только по закону (двойной платёж, файл не открылся), до 10 дней; замена разбора 14 дней; для набора — подарок; после возврата не продаём; пауза продаж на время заявления.
- Сводка — ежедневно. Wildberries — по правилам площадки.
